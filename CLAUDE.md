- Demos you can use to test stuff in ../nudeps-demos/
- When running tests via `npx htest`, pass `--verbose` to see output for passing tests (htest suppresses output in non-TTY/piped contexts unless there are failures or `--verbose` is set).
- In addition to running tests, verify against the demos: regenerate import maps **and diff them against a baseline to confirm no unintended changes** (regenerating is only useful as verification if you actually compare). Snapshot the maps on unchanged code first, then regenerate with your change and diff — a behavior-affecting change should produce only the diffs you expect. Use `npm run init-demos` (not `npm run demos`) for a cache-free comparison, since the install cache can replay stale per-package maps and mask a real difference. Note: the demos link nudeps via `npm link`, so a stale local `node_modules` (e.g. an out-of-date `@jspm/generator`) can break every demo independently of your change — run `npm install` first if the maps come out empty/erroring.
- `SKILL.md` is an AI agent skill that ships with the package. After any code change, check if `SKILL.md` needs a corresponding update to stay accurate.
